01 / Start with the problem

A useful tool begins with a specific task and a person who needs it.

02 / Make it inspectable

Source, setup instructions and tests should help someone understand what they're running.

03 / Name the boundaries

A prototype, a project guide and a deployed service are different things. Each project explains its current scope.

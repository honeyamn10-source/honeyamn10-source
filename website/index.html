Tier Definitions

Tier A

Production-ready. Clean CI, comprehensive tests, accurate docs, deployed site.

Tier B

Active development. Working CI, test suite, deployed site, some docs gaps.

Tier B/C

Complex or early. Slow/heavy tests, partial docs, site deployed.

Standards

  • Honest metrics: All test counts, versions, and features verified from code — no marketing fluff.
  • Consistent identity: Shared design system, monogram logos, accurate READMEs.
  • Deployed sites: Every suitable repo has a GitHub Pages site at honeyamn10-source.github.io//
  • CI/CD: GitHub Actions for lint, test, typecheck, deploy.
